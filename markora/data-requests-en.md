# Markora Data Deletion and Requests

The current version of Markora has no developer-hosted account, cloud document database, or behavior-analytics backend. There is generally no online personal profile for Markora to delete on your behalf.

## Delete local content

1. **Saved documents and image assets:** delete the Markdown file and its `assets` folder in Files or the file provider where you saved them.
2. **Unsaved drafts and recent records:** these are used only in local app data. Deleting the App removes data in its app sandbox; save or export anything you need first.
3. **Scan content:** scan images and OCR text are not uploaded to Markora. If you saved the result as a document or export, delete it at that location.
4. **Apple subscription records:** Apple manages purchases, billing, and refunds. Use your Apple Account or [Apple’s Data & Privacy page](https://privacy.apple.com/) for those records.

## Submit a request

If you believe the maintainer received personal information through support, or you need help confirming deletion steps, use [GitHub Issues](https://github.com/harrysxu/show-pages/issues). Do not post identity documents, full receipts, document text, scan images, or payment information in a public issue. Start with “data request” and wait for a suitable private channel.

Because Markora has no cloud account system, we cannot recover a document deleted from your device or chosen file location, and we cannot change Apple subscription records.
