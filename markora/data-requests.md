# Markora 数据删除与请求说明

Markora 当前没有开发者托管的账号、云端文档数据库或行为分析后台，因此通常没有可由 Markora 代为删除的在线个人资料。

## 删除设备上的本地内容

1. **已保存文档和图片资源**：在“文件”应用或您选择的文件提供商中删除 Markdown 文件及同目录的 `assets` 文件夹。
2. **未保存草稿和最近记录**：这些信息只在本机应用数据中使用。删除应用会移除应用沙盒内的数据；卸载前请先导出或保存需要保留的文档。
3. **扫描内容**：扫描产生的图像和 OCR 文字不会上传到 Markora。若您已将结果保存为文档或导出文件，请在对应保存位置删除。
4. **Apple 订阅记录**：购买、账单和退款记录由 Apple 管理，需要通过 Apple 账户或 [Apple 数据与隐私页面](https://privacy.apple.com/) 处理。

## 向我们提交请求

如果您认为维护者通过支持沟通收到过您的个人信息，或需要协助确认删除步骤，请通过 [GitHub Issues](https://github.com/harrysxu/show-pages/issues) 联系。请不要在公开问题中提交身份证件、完整收据、文档原文、扫描图片或付款信息；可以先只写“数据请求”，等待维护者提供合适的私密沟通方式。

由于本应用没有 Markora 云端账号系统，我们无法恢复已从设备或您选择的文件位置删除的文档，也无法替 Apple 修改订阅记录。
