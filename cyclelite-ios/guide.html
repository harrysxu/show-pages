使用指南

从第一条记录到备份恢复，了解期简的日常使用方式。

更新于 2026 年 9 月 19 日 · 适用版本 1.0.0

01 / 从最近一次开始

首次打开时，可以补充最近一次经期的开始日和结束日，也可以跳过。提醒默认关闭，是否开启由你决定。

  1. 在「今天」点击「经期开始」，记录今天为开始日。
  2. 经期结束后点击「经期结束」，记录今天为结束日。
  3. 要更正日期，点击首页的最近记录，或在「日历」选择已记录日期后点击「编辑」。
  4. 「记录今天」可以单独添加当天的经量、感受和备注；这些信息是可选的。

开始日和结束日不能晚于今天，结束日不能早于开始日。编辑时若与已有经期重叠，应用会要求你明确确认合并；合并会保留症状和不同的备注。

02 / 回顾自己的节奏

「日历」区分实际记录和预计窗口，并标记有日记的日期。「趋势」展示已记录的周期长度和已结束经期的持续天数。

周期长度指相邻两次开始日期的间隔；经期长度包含开始和结束两天。记录不足时使用设置中的默认值。点击首页预计窗口，可以查看参考周期、典型长度和不确定范围。

周期会自然变化。预计窗口不代表确定日期，不适用于避孕、确认排卵、判断怀孕或诊断。如果症状让你担忧，请咨询合格的医疗专业人士。

03 / 语言和日期保持一致

支持简体中文和英文。前往 iPhone「设置 → App → 期简 / CycleLite → 语言」选择应用语言，也可从应用「设置 → 应用语言」进入系统设置。

如果没有出现语言选项，请先在「设置 → 通用 → 语言与地区」添加另一种支持的语言，然后重新查看应用设置。

日期文字、月份、星期和日期选择器遵循应用语言，日期顺序与每周起始日结合设备地区显示。例如同一天可以显示为「2026年8月8日」「August 8, 2026」或「8 August 2026」。切换语言后，你写下的备注保持原样。

04 / 导出和恢复

  • JSON 备份：在「设置 → 导出 JSON 备份」保存完整记录和偏好设置，适合恢复或迁移。
  • CSV 数据：适合在表格软件中阅读；CSV 不用于应用内恢复。日期固定为 yyyy-MM-dd，列名和经量代码保持稳定，症状名称使用导出时的应用语言。
  • 导入：选择不超过 10 MB 的期简 JSON 备份，核对预览中的条数，选择合并或替换，再确认导入。
  • 合并：保留其他本机记录，同一标识的记录采用备份版本。重叠经期或同一天的不同日记发生冲突时，不会导入。
  • 替换：本机记录将被备份记录替换，建议先导出当前数据。「恢复备份中的设置」是独立选项。

JSON 和 CSV 导出文件没有由应用额外加密，可能包含个人健康信息。保存到你信任的位置；如果选择云盘，文件是否上传由该文件提供方及你的设置决定。

05 / 隐私锁与提醒

隐私锁通过系统设备认证保护访问，支持设备配置的 Face ID、Touch ID 或密码。启用或关闭隐私锁需要验证身份。

经期窗口提醒是本地通知，可以提前 1、2、3 或 5 天提醒。默认隐私模式仅显示「有一项健康提醒」；详细模式会显示预计日期。通知还需要系统授权，关闭提醒会取消待发提醒。

删除单条记录需确认；「设置 → 删除全部数据」会清除本机记录、偏好设置、应用维护的恢复副本和应用提醒。你保存到其他位置的导出文件，以及系统备份，需分别管理。
