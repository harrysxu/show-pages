# CycleLite / 期简公开文档

原生静态 HTML + CSS；不需要构建、第三方字体、脚本或统计服务。中文入口为 `index.html`，英文入口为 `en/index.html`。所有子页面都提供对应语言切换。

## 本地预览

在 show-pages 仓库根目录执行 `python3 -m http.server 8765`，访问 `http://localhost:8765/cyclelite-ios/`。

## 内容维护

- 本文档对应当前 1.0.0 开发版本，不宣称 App Store 已上架。
- 隐私政策基于本机 JSON 存储、本地通知、系统认证和用户主动导出；区分应用同步和 iOS 系统备份。
- 暂使用开发者 GitHub 主页作为联系入口；正式支持邮箱待确认后同时更新中英文 support.html。
- App Store Connect 可使用发布后的隐私政策和支持页面地址；需先验证线上可访问以及联系渠道有效。
- 功能、数据处理或联系渠道有变化时，同时更新中英文页面和修订日期。
- 这里不包含用户记录、备份或包含个人健康信息的测试截图。
