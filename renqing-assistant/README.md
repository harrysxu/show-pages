# 回礼有数公开页面

这个目录是不依赖构建工具的静态 GitHub Pages 站点，包含应用介绍、隐私政策、使用条款和支持页面。

## GitHub Pages

在 `harrysxu/show-pages` 仓库的 Pages 设置中选择发布分支根目录后，页面地址为：

- 首页：`https://harrysxu.github.io/show-pages/renqing-assistant/`
- 隐私政策：`https://harrysxu.github.io/show-pages/renqing-assistant/privacy.html`
- 使用条款：`https://harrysxu.github.io/show-pages/renqing-assistant/terms.html`
- 支持：`https://harrysxu.github.io/show-pages/renqing-assistant/support.html`

发布后，App Store Connect 的 **App 信息 → App 隐私**按应用实际情况填写；**App 审核信息**中的支持 URL 填支持页面，隐私政策 URL 填隐私政策页面。
