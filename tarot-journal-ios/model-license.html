English

The app bundles Qwen/Qwen3-1.7B at base-model commit 70d244cc86ccca08cf5af4e1e306ecf908b1ad5e, released under Apache License 2.0. The license text is included with the app.

The bundled INT4 Core ML conversion is from dreamer1cc/hovor-qwen3-1.7b-coreml-int4, pinned to commit fcacdb128d05e120232098c46e6df33a6d742b45. Its model card states that the converted model uses Apache-2.0. It uses coremltools 8.3 INT4 palettization (group size 32) and a 512-token context. The model weights are 1,017,099,136 bytes with SHA-256 4e46fbab5661dd1aee3dbf057793c1a4b7066bc80567288384284311820f28f8.

The app uses CoreML-LLM 1.9.0 (MIT) for on-device inference and bundles the tokenizer. After the user explicitly taps Generate, the question, notes, and spread are processed on device. The app does not download model files at runtime or send this input to a server. Core ML is an Apple machine-learning framework and Apple trademark.

Model attribution and license details are also bundled in the app’s Qwen3-1.7B model resources.
