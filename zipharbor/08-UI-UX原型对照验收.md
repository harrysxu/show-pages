# ZipHarbor UI/UX 原型对照验收

日期：2026-10-01。设计基准：`app-prototype.html`。实现入口：`ZipHarbor/ZipHarbor.xcodeproj`。原型内的 ZipKit 是设计稿旧名，新工程品牌为 ZipHarbor。

## 验收方法与结论

实际打开 Safari 中的交互原型，逐页检查首页、归档详情、两步创建、任务、设置和底部弹层；通过 XCTest 在 iPhone 14 模拟器及 iPhone 14 / iOS 27.0 真机运行真实流程并保存截图，另在 iPad mini 模拟器验证创建往返和英文深色外观。并排证据见 [原型与实现对照](migration-comparison.html)，可切换真机与模拟器。

新界面已使用原型的信息层级、颜色、卡片、按钮、筛选和任务结构。归档详情和创建页按原型隐藏底部导航，主页/任务/设置显示三个固定入口。完整真机 UI suite 为 12 项通过、1 项合成媒体用例跳过、0 失败，另有 1 项补充冲突 UI 通过；真机截图已逐页检查，密码自动解压、结果关闭、目录选择取消、两步创建、英文深色、最大字号与系统 Files 导入均取得实际证据。

这不是逐像素一致性断言。字体由 SwiftUI 原生排版，图标采用 SF Symbols；状态栏、安全区、系统文件/照片选择、分享面板和 sheet 外框由 iOS 绘制。真机截图左上方的屏幕会话指示来自系统。真实文件名、大小、时间、项目数与原型演示值不同。原型固定窗口尺寸，原生界面随设备和 Dynamic Type 调整；长归档标题时动作移到下一行，最大字号时布局纵向扩展。这些差异在对照页可直接查看。

## 视觉规格

浅色背景 `#f3f5fa`、纸面 `#ffffff`、主文字 `#171c2e`、次文字 `#8990a3`、分隔线 `#edf0f5`、主色 `#5669ee`、浅蓝 `#eef0ff`、成功绿 `#19896b`。渐变颜色为 `#596cf1 → #737ef4 → #8a90f4`。内容水平边距 20 pt，普通卡片圆角 16–20 pt，首页渐变卡片 22 pt，主按钮 14 pt。颜色由统一 DesignSystem 管理。

自定义分段选择和开关避免新版 iOS 默认玻璃胶囊改变原型观感。图标保留原型线性风格与文件类型配色，使用系统可用符号，不引入外部图片授权依赖。

## 可用性与国际化

- 中文和英文界面均测试，用户文件名不翻译。日期、字节单位按系统格式显示。
- 英文冲突选项修正为 Ask each time、Keep both、Skip、Replace，避免显示内部枚举键；补充 UI 回归验证按钮与实际重名行为。
- 字体随 Dynamic Type 缩放。大字时页头操作移到下一行，快捷操作与位置入口改为单列；设置标题和说明可换行。
- 主要交互提供 accessibility label/value 和稳定测试 ID；密码使用 SecureField，展示错误后可重试。
- 点击图标与开关留出 44 pt 容器。常规字体下维持原型的视觉尺寸；归档筛选、密集文件列表和最大字号仍需后续真人 VoiceOver/触控复核，自动测试不等同于无障碍全面认证。
- 用户选中照片或视频后才读取文件，不要求相册全量权限。原型的模拟导入弹层在产品中替换成原生系统选择器。
- iPad 内容宽度限制为 700 pt 并居中，不放大字号；两步创建和深色外观流程通过。
