# ZipHarbor 新工程迁移与功能映射

迁移日期：2026-10-01。开发入口为 `ZipHarbor/ZipHarbor.xcodeproj`，scheme 为 ZipHarbor。旧 `app/` 保留作迁移来源。应用标识为 `com.xiaolongxu.zipharbor.app`，与旧应用独立，不迁移旧数据库。

## 工程与产品边界

iOS/iPadOS 17+，Swift 6，SwiftUI，SwiftData 本地存储。保留用户初始化的原生 Xcode 工程、同步文件夹与三个 targets；移除模板 Core Data、CloudKit、推送和多平台配置。iCloud Drive 由用户通过系统 Files 授权访问，不代表使用 CloudKit。ArchiveKit 1.0.0 精确锁定；本地打包完整依赖许可，设置页可查看。

本次实现旧版真实能力及 HTML 原型的实际交互。不包含账号、广告、云端解压、完整文件管理器、回收站、快捷指令、跨进程断点续传或加密 7z 创建。加密 RAR 保持明确不支持。分卷指 `.zip.001` 原始切片方式，不承诺传统 split ZIP/多卷 RAR 的全面兼容。

## 文件位置与默认值

- 导入文件复制至 Documents/Library/随机目录，分卷保留在同一目录。
- 本机输出使用 Documents/Downloads，对系统 Files 开启文档共享。
- 默认解压位置为压缩包所在位置；打开目标弹层时读取真实设置。
- 每次解压生成按归档名称命名的结果目录，重名条目按所选策略处理。
- 本机路径以 Documents 相对路径保存，避免沙盒绝对路径变化导致文件失联。
- 外部位置使用书签，执行期间保持访问权限，失效时显示重新选择位置的错误。
- 串行任务队列；暂停当前任务保留执行位置并等待恢复。系统终止后的任务标为已中断，可以从头重试。
- 任务记录保留 30 天；过期和清除记录均不删除结果文件。
- 默认浅色，用户可开启深色并持久保存。
