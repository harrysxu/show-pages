# PDF 与文件工作台竞品分析

分析时间：2026-09-30。价格和商店数据会随地区、促销、系统版本和账号状态变化，本文把公开商店资料和官方价格页面作为方向判断依据，不把它们当作最终定价依据。

## 1. 结论先行

用户愿意为 PDF 工具付费，但付费购买的是“尽快、可靠地完成一个文件任务”，不是一个功能数量更多的 PDF 阅读器。

市场已经证明了三种付费需求：

- 专业办公用户愿意为编辑、OCR、转换、压缩和跨设备使用付费。
- 高频扫描用户愿意为更好的扫描、OCR、同步和导出付费。
- 企业和 Adobe 用户愿意为跨平台、云服务、协作和 AI 付费。

同时，公开评价反复出现四类不满：订阅和升级提示过多、基本功能被锁定、界面变复杂、更新后稳定性或已有购买权益受到影响。

因此，我们不能靠“再做一个全功能 PDF App”取胜。可行的切入点是：

> **一个本地优先、中文办公流程优先、把单个 PDF 任务快速做完、定价透明的 Apple 原生工具。**

我们有机会在这个窄定位上超过竞品的任务体验和信任感，但短期不可能在品牌、Office 转换、企业协作、AI 规模或功能广度上超过 Adobe。

## 3. 竞品拆解

### 3.1 PDF Expert

**强项**

- 读 PDF、搜索、夜间模式、标注、表单、签名。
- 编辑文字和图片、链接、目录。
- 合并、拆分、页面重排、压缩。
- OCR、Office/PDF/图片格式转换。
- 密码保护和永久打码。
- iPhone、iPad、Mac 和 Vision Pro 的统一产品线。
- Apple Pencil、演示模式和工程图测量等高级能力。

**收费方式**

- 官方价格页同时展示周付、年付和一次性买断。
- 页面展示的中国区示例为周付 ¥800、年付 ¥9,100、买断 ¥22,000；上线时必须用 App Store Connect 的实际地区价格重新确认。

**用户愿意付费的原因**

- 复杂合同或学习资料可以在一套工具中完成。
- 多设备使用和高级编辑节省了桌面软件切换。
- 专业用户对稳定的标注、签名和页面操作有明确价值判断。

**公开评价中的问题**

- 近期评价反复提到界面改版、工具变难找、Apple Pencil 操作异常和崩溃。
- 有用户抱怨 OCR 能力没有和 Scanner Pro 统一。
- 订阅升级提示、旧买断权益变化和价格被认为不透明。

**对我们的启示**

- 可以学习它的页面缩略图、标注和跨设备信息架构。
- 不要在第一版复制它的全文本编辑、工程测量、AI 和 Office 转换。
- 用“任务入口 + 清晰进度 + 原文件不变 + 一键导出”减少它被评价为复杂的部分。

### 3.2 Adobe Acrobat Reader

**强项**

- 品牌、格式兼容性和企业生态最强。
- 查看、搜索、标注、评论和免费 Fill & Sign。
- 付费编辑、OCR、合并、拆分、转换、压缩、密码保护。
- 连接 Adobe 云、Google Drive、Dropbox、OneDrive 等。
- 订阅覆盖桌面、Web 和移动端，增加 AI Assistant、PDF Spaces 和摘要能力。

**收费方式**

- 免费阅读、基础标注和填写/签名。
- 7 天试用后订阅高级功能。
- 官方资料明确把 Acrobat Standard、Pro、Studio 和 AI 作为不同订阅层级。

**用户愿意付费的原因**

- 企业已有 Adobe 工作流，兼容性和云协作价值很高。
- 转换、OCR、批量处理和跨平台访问是高频办公需求。

**公开评价中的问题**

- 用户认为编辑、压缩等基本任务被付费墙挡住。
- 评价反复提到 AI 和订阅提示干扰任务。
- 有用户认为发送时得到云链接，而不是直接得到文件附件。
- 移动端加载、文件打开和表单编辑偶尔不稳定。

**对我们的启示**

- 我们不可能在企业生态和格式兼容性上超过 Adobe。
- 可以在无账号、无云上传、直接导出本地附件、中文任务流程和价格透明上形成差异。
- 对普通个人用户，先解决“扫描/签名/压缩/分享”比提供 AI 对话更有价值。

### 3.3 Scanner Pro

**强项**

- 自动识别边缘、透视校正、去阴影和多页扫描。
- 扫描生成可搜索 PDF，并支持 OCR 和全文搜索。
- 填写、签名、批注和多种格式导出。
- iCloud 同步，并连接 Dropbox、Google Drive、Box、OneDrive、WebDAV 等。
- 支持 25+ 语言，包含简体和繁体中文。

**收费方式**

- 免费下载，把扫描质量、OCR、同步、导出和高级工作流作为长期价值。
- 公开评价显示老用户曾经一次性购买，后来对订阅升级提示和权益变化不满。

**用户愿意付费的原因**

- 扫描质量比系统相机拍照明显更好。
- 文档扫描是高频、明确、节省时间的任务。
- 纸质材料、收据、证件和合同需要 OCR、整理和分享。

**公开评价中的问题**

- 近期评价提到扫描裁切、重复页面、颜色和稳定性回退。
- 升级提示被认为打断扫描流程。
- 有用户期待 iCloud Drive 文件夹双向同步，而现有体验不完全等同于普通同步文件夹。
- 用户对从买断变成订阅尤其敏感。

**对我们的启示**

- 扫描质量必须作为核心工程指标，而不是普通相机加滤镜。
- 首版应该只做少量高质量流程，避免扫描过程中弹出销售页面。
- 可以对“导入已有 PDF 后快速签名/压缩/分享”做 Scanner Pro 不够聚焦的补充。

### 3.4 PDFgear

**强项**

- 移动端产品较轻，界面和功能入口相对直接。
- 查看、打印、标注、页面新增/删除/旋转/提取、表单和签名。
- 支持设备和 iCloud 文件管理。
- 商店文案明确宣传所有功能免费、无水印、无页数限制。

**收费方式**

- iOS 商店文案主张免费使用全部功能。
- 这证明用户对“基础 PDF 任务免费完成”的期望很强，也让通用工具的订阅转化更困难。

**用户愿意使用的原因**

- 不需要马上注册或订阅。
- 基础任务覆盖够用，功能入口简单。

**局限和机会**

- 评价规模和品牌信任明显小于 Adobe、PDF Expert 和 Scanner Pro。
- 与成熟产品相比，扫描、跨设备、企业协作和高级转换能力较弱。
- 我们可以在隐私说明、中文办公模板、稳定性和 Apple 原生整合上建立更强信任，但不能假设用户愿意为 PDFgear 已经免费的同类功能付费。

### 3.5 iLovePDF

**强项**

- 扫描、OCR、JPG/Office/PDF 转换、批注、签名。
- 合并、拆分、旋转、压缩、密码保护、页码和水印。
- 连接 Google Drive 和 Dropbox。

**收费方式**

- 基础功能免费，Premium 提供月付和年付自动续订。
- 这种模式证明转换、压缩、OCR 和批处理可以形成订阅价值。

**对我们的启示**

- “转换工具箱”覆盖面广，但容易变成入口复杂、结果质量难以解释的工具集合。
- 我们应该把高频任务做成明确的向导，暂时不做大量格式转换。

## 4. 功能取舍

### P0：必须支持

| 功能 | 原因 | 本地实现可行性 |
|---|---|---|
| Files/Share Sheet 导入 | 所有竞品的基本入口，决定能否进入真实工作流 | 高；Files、Share Extension、security-scoped URL |
| 文档扫描和多页 PDF | Scanner Pro 验证了付费价值 | 高；VisionKit + Photos/Files |
| 中文/英文本地 OCR | 让扫描 PDF 可搜索、可复制 | 中高；Vision 的文本识别，需真机测试准确率 |
| 查看、搜索和基础标注 | 系统工具和竞品的最低标准 | 高；PDFKit |
| 合并、拆分、旋转、重排 | 高频、结果明确、无需云端 | 高；PDFKit/CGPDFDocument |
| 签名、表单文字、勾选 | 直接对应合同和申请材料 | 高；PDFKit/PencilKit |
| 压缩和文件大小预览 | 用户常为邮件、上传限制而付费 | 中；图像重采样和 PDF 重建 |
| 直接导出文件 | 解决 Acrobat 的链接分享不适用于所有收件人的问题 | 高；Files/Share Sheet |
| 购买、恢复购买和家庭共享 | 形成可持续收入且无需后端 | 高；StoreKit 2 |

### P1：验证后支持

| 功能 | 原因 | 风险/做法 |
|---|---|---|
| 真正永久打码 | 专业和隐私场景有价值 | 不能只放黑色标注；需重建 PDF 内容或栅格化导出并做文本提取测试 |
| 密码保护和移除密码 | 竞品常见，适合文件分享 | PDFKit 覆盖有限，需测试不同加密 PDF |
| 批量任务 | 提高 Pro 付费价值 | 先支持压缩、合并和重命名三种批处理 |
| 页面编号、水印和模板 | iLovePDF 的成熟付费点 | 先做导出向导，避免首页功能泛滥 |
| Shortcuts/App Intents | 充分利用 Apple 生态，服务重复任务 | 只暴露稳定的无 UI 操作 |
| iPad 分屏、拖放和 Apple Pencil | Apple 用户的重要差异点 | 需要实际 iPad 和 Pencil 测试，不靠模拟器判断 |

### P2：暂缓

- 编辑任意已有 PDF 文本和图片。
- PDF 与 Word/Excel/PPT 的高保真双向转换。
- AI 摘要、问答、翻译和语音功能。
- 企业协作、评论流、账号体系和自有云盘。
- 传真、在线签署和服务器 OCR。

这些能力要么是 Adobe/PDF Expert 的护城河，要么需要云服务和持续成本。首版加入会放大开发风险，却不一定增加早期付费转化。

## 5. 我们如何实现和超过竞品

### 5.1 产品策略

首页只提供五个任务入口：**扫描、签名、压缩、合并/拆分、导入文件**。用户完成一个任务后再看到高级能力，而不是先看到功能墙。

每次处理都遵循四个原则：

1. 原文件默认不修改，结果另存为新文件。
2. 处理前显示页数、文件大小、预计输出大小和权限范围。
3. 处理过程中不弹出销售页面。
4. 导出后能直接得到文件，而不是只能发送云链接。

### 5.2 技术实现

- SwiftUI：iPhone、iPad、Mac 统一界面和可访问性。
- VisionKit：文档扫描、自动裁切和透视纠正。
- Vision：设备端中文/英文 OCR。
- PDFKit：阅读、搜索、标注、签名、页面组织。
- Core Graphics：页面合成、图像重采样和压缩导出。
- PencilKit：iPad 手写签名和标注。
- Files、DocumentGroup、Share Extension：进入和离开用户文件工作流。
- App Intents：压缩、合并、扫描结果导出等自动化。
- StoreKit 2：Pro 权益、恢复购买、家庭共享和价格本地化。
- SwiftData：保存最近任务、签名和设置；不复制不必要的文件内容。

### 5.3 能超过什么，不能超过什么

| 维度 | 判断 | 依据 |
|---|---|---|
| Adobe 的品牌、企业账号和格式兼容 | 不能在短期超过 | 需要多年生态、桌面端和企业资源 |
| PDF Expert 的完整编辑和高级工具数量 | 不能在首版超过 | 全文编辑、Office 转换和工程工具复杂度高 |
| Scanner Pro 的扫描成熟度 | 首版目标是达到可用，后续才可能超过 | 需要大量真机拍摄和边界样本 |
| PDFgear 的免费功能广度 | 不应正面比较 | 对方已经把免费作为主要卖点 |
| 任务入口、无打扰流程和中文办公场景 | 有机会超过 | 竞品公开评价集中暴露复杂、升级提示和中文流程缺口 |
| 隐私透明和本地优先 | 有机会形成品牌差异 | 只使用 Apple 本地框架，不需要上传文件 |
| Apple 原生自动化、Files 和 Pencil 体验 | 有机会超过通用跨平台产品 | 从架构开始围绕 Apple 设备设计 |

## 6. 收费建议

不要把阅读、基础标注和一次性的简单签名全部锁住，否则会直接输给系统工具和 PDFgear。建议采用：

### 免费版

- 无限查看、搜索和基础标注。
- 每月 3 次扫描/OCR。
- 每月 3 次压缩或合并。
- 单次签名和导出可完成完整任务。

### Pro 买断或订阅

- 无限 OCR、压缩、合并和批处理。
- 高级签名、批量任务、永久打码、密码保护。
- Shortcuts、模板和报告。
- 早期优先测试一次性买断，价格带建议 ¥48–98；如果后续提供持续更新的转换或同步服务，再增加低价年订阅。

定价必须在用户完成一次免费任务后展示，并明确写出权益、价格、周期和恢复购买入口。不要使用周订阅作为默认方案。

## 7. 验证方案

在开发复杂功能前，用真实设备和 30–50 名目标用户做 TestFlight 验证，至少测三条任务：

1. 手机扫描 5 页中文合同，生成可搜索 PDF 并分享。
2. 从 Files 导入 PDF，签名后通过邮件发送附件。
3. 将大 PDF 压缩到指定大小，并保持页面可读。

记录以下指标：

- 首次打开到完成第一个任务的时间。
- 任务成功率和需要帮助的步骤。
- OCR 错误率、扫描裁切错误率、导出失败率。
- 用户是否主动尝试第二次任务。
- 看到 Pro 权益后愿意支付的比例。
- 用户对买断、年订阅和免费限制的选择。

只有当任务成功率、稳定性和付费意愿达到可接受水平，才进入 P1 的打码、密码保护和批处理开发。公开竞品的评分证明市场存在，真实用户的任务完成和付费数据才决定我们是否继续。
