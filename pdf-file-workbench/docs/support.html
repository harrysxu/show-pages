PaperFlow / 纸间 · 技术支持

技术支持

PaperFlow 是 iPhone 和 iPad 上的本地 PDF 工具。应用不要求账号，也不会把用户文件上传到 PaperFlow 服务器。

常见问题

文件没有出现在应用里

请从“文件”或分享面板重新选择文件，并确认应用有权访问你主动选择的文件。分享扩展导入后，打开 PaperFlow 主应用即可完成消费。

OCR 或扫描结果不准确

请在光线均匀、页面平整且文字清晰的情况下重新扫描。OCR 在设备端完成，原文件不会被覆盖。

如何恢复 Pro

打开应用内购买页面并选择“恢复购买”。购买和恢复由 Apple StoreKit 处理；同一 Apple 账户的家庭共享资格按 Apple 规则生效。

联系支持

请在 PaperFlow 公开支持页面 提交问题，并附上系统版本、应用版本和可复现步骤。请不要上传包含身份证件、合同或其他敏感信息的原始文件。
