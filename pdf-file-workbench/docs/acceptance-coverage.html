本轮补查与修正

  1. OCR 文本顺序与页码：原先 TXT / Markdown 导出枚举 OCR 记录，而页面整理只改变 PDF 页序，导致重排后文字顺序与页码错误。新增真机用例用中英文已知文本，组合重排、复制和部分页面已识别的场景，分别回读实际 .txt / .md 文件并对照完整预期内容，也核对复制文字的数据源。修正前该用例出现 3 项断言失败；修正后通过。现在按当前文档页序输出，并使用实际页码，未识别页不会导致后续页码提前。
  2. 批量拆分内容：原先主要核对输出数量、文件存在及检查点恢复。本轮补充逐个打开拆分 PDF，确认每个只有一页，逐页文字与来源相应页面相同。
  3. UI 图标资源缺失：人工复核原有 54 张真机截图，发现 Pro 顶部和家庭共享图标为空。检查界面引用后补齐 14 个缺失图标，沿用 HTML 原型的 Lucide 资源。静态核查 83 个可对应 Lucide 的名称，均已在资源中；最终 App 包也包含全部新增图标。普通启动的真机画面确认 Pro 图标已显示。图标资源补齐没有调整布局、色值或字号。
本轮证据 结果
修正前结果 OCR 文本导出用例 1 项失败，3 个断言问题；保留失败证据。
修正后真机结果 21/21：20 项原生模型测试与 1 项 OCR UI 测试；包含本地 StoreKit。
图标补齐后的 UI 巡检 1/1，该用例遍历 19 路由。它不是 19 个独立用例，也不自动验证每一个图标像素。
资源核查 83 个已知图标名称核查；最终 App 含全部 14 个补充资源。
最终普通启动 Pro 页 顶部和家庭共享图标可见，未执行真实购买。

图标巡检在补齐最初 12 个资源后运行；随后补齐删除线与斜向箭头两个标注图标，最终构建成功并重新安装。最终资源核查包含这两个图标，不把它们描述成已逐个操作验收。原先 35 个不同真机用例，加上新增 OCR 文本导出用例，累计 36 个不同用例有通过记录；多批次复测不相加计算独立用例。

生成文件的正确性

类型 已有实际验证 验收边界
页面整理 / 合并 回读 PDF 页数、文字标记、选定顺序、旋转状态；撤销数据；来源原件字节不变。 未逐项覆盖所有提取 / 插入 / 范围拆分组合与不同来源 PDF。
批量拆分 每个 PDF 一页、文字对应来源页；全部输出留存；持久化后检查点和 URL 恢复。 不是全部批处理类型的内容验收。
压缩 真实文件体积下降、原生文字保留、图形内容未整体栅格化；无目标大小及无效目标拒绝；不可达目标有警告。 未量化所有清晰度 / 色彩档位，未逐页进行像素或印刷质量验收。
页码 / 水印 / 纸张 页码起点与跳过封面规则；输出含水印文字；A4 竖横尺寸正确并保留文字 / 矢量。 全部位置、透明度、图片水印与范围组合的输出渲染仍待补齐。
OCR 可搜索 PDF 真实 Vision 对已知中英文测试图识别；文字层可提取与搜索；修正后新文字替代旧文字。 样例通过不代表真实拍摄文字准确率达标；倾斜、模糊、多栏等材料仍需验收。
OCR TXT / Markdown 本轮回读 UTF-8 文件与完整预期文本；重排、复制、部分识别的实际页码正确。 不等于完整 OCR 识别精度或所有特殊字符 / 长文档验收。
签名 / 表单 / 标注 签名图像进入预览；去背景像素验证；坐标 / 旋转恢复；文字表单、单选互斥与下拉导出值；编辑后分享含编辑内容。 所有标注类型、字号、签名位置与表单固定后的外部阅读器视觉一致性仍待验收。
永久打码 输出结构白名单验证；文字层不可提取 / 搜索；批注、表单、元数据移除；未确认时不能分享。 结论对应测试样例与安全检查，不宣称已覆盖所有第三方 PDF 结构。
密码与权限 / 清理 错密码失败、正确密码解锁；打印 / 复制权限；编辑分享保留来源加密；附件默认保留、显式清理后不存在。 尚未全面操作不同外部阅读器；PDF 权限是否被遵守取决于阅读器。
Files / 分享扩展 系统保存、重新导入、重名副本可读；真实扩展导入后主 App 正确打开；再次重启无重复消费。 本机目录通过；iCloud 与其他提供方生命周期待验收。

处理引擎导出时也会检查 PDF 可读取、页数、预期加密状态、原件哈希；打码时增加图像结构和不可提取文字检查。因此结果页“输出已验证”表示这些程序检查通过，不表示 OCR 文字完全准确或视觉设计已经签收。

此前处理层证据为既有 19 项处理集成与 9 项领域测试：Package 日志。它们运行于 macOS；原生模型的实际输出与恢复逻辑另有 iPhone 真机证据，不能混称所有处理用例都在真机执行。

UI 与交互

  • 功能与布局已有覆盖：真机 UI 16 个独立方法通过；19 路由、返回与取消、主命令可操作、键盘输入、横屏、大字号、草稿恢复、结果继续处理、批处理与流程暂停恢复。iPad 和小屏模拟器另有记录。
  • 本轮视觉复核：已查看原有 54 张真机截图的六张合图，索引；图标缺失已修正。新增 19 路由截图与 索引 保留修正后证据，普通启动最终 App 的 Pro 页另有截图。合图中横屏截图保持设备原始方向，不是应用旋转异常。
  • 视觉一致性尚未签收：HTML 原型未同步用户后续批准的扫描与全流程交互简化；尚未完成所有页面 / 弹层 / 状态的颜色、间距、字体、图标和布局逐项对照，也未完整检查深色模式、对比度与 VoiceOver。界面元素存在和可点击不能证明视觉一致。
  • 用户体验尚未完整验收：尚未执行首次使用者的任务观察；真实 iPad 分屏 / Pencil 和纸张实拍仍缺证据。Pro 页购买 / 恢复入口的所有屏幕尺寸与字号组合也不在此次完整验证范围。
  • 国际化已接入三语，发布签收仍有边界：主 App、分享扩展、公共包、权限说明、快捷指令和输出标签已支持简体中文、繁体中文、英文。三语资源和编译产物审计、三语 TXT / Markdown / 报告实际回读、iPad 三语各 19 路由、真机英文巡检及切换语言后的文件 / 自定义流程保留已有通过证据；逗号小数输入已修正。最终大字号布局在小屏和 iPad 模拟器交互复测通过，真机最新复测被系统“无法验证 App，需要互联网连接以验证开发者”弹窗阻塞。系统真实语言切换及扩展三语成功导入后来已在模拟器通过；快捷指令宿主、完整 VoiceOver 与全部界面状态仍待补齐；详细结果及截图复核修正见 国际化实现与验收。
