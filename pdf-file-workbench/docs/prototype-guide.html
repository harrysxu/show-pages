纸间 HTML App 交互原型

直接在浏览器打开 prototype.html。文件内置全部脚本、图标、PDF 阅读器和示例文档，离线可用，无需启动服务。顶部可以切换 iPhone / iPad 预览；在手机浏览器中自动铺满可用区域。

本次交付仅包含 HTML 原型，不包含 SwiftUI、Xcode 工程或原生 App 开发。

本轮体验优化

本轮围绕重复处理文件的日常需求优化：让用户更快开始任务、中断后继续，以及复用自己的签名、填写资料和处理流程。

  • 首次使用首页提供导入、扫描和明确标注的示例文件；使用后首页展示当前草稿、最近文件和置顶流程。
  • 从工具中导入文件后自动返回对应工具；切换工具保留当前页，重新打开文件恢复阅读位置。
  • 草稿支持刷新后恢复、暂停流程和放弃编辑；扫描页面与手动修正的 OCR 文字也可恢复。
  • 结果页展示本次处理效果、真实文件大小、大小限制状态和处理前后预览；后续操作使用新生成的结果文件。
  • 支持保存多个签名以及姓名、联系电话、公司资料，减少重复填写。
  • 手机压缩主操作固定在底部，次要参数折叠；签名工具分为常用操作和更多操作。iPad 文档区与参数区独立滚动，侧栏可收起。
  • 主要按钮和图标操作使用至少 44px 的触控区域。

常用流程

原型提供四个可编辑、删除和置顶的流程。运行前可确认步骤和参数，选择已有文件、导入文件或扫描；人工步骤完成后执行 PDF 输出。

流程 默认步骤
合同签署 填写与签名、压缩、清理元数据、命名与导出
每月报销 整理页面、识别与复核文字、添加页码、灰度压缩、清理元数据、命名与导出
项目交付 整理页面、添加页码并跳过封面、交付水印、轻度压缩、清理元数据、命名与导出
材料提交 整理页面、强力压缩并检查 2 MB 限制、清理元数据、命名与导出

流程实际生成 PDF，保留压缩、页码、水印、元数据和命名参数。文件名支持 {原名}、{日期}、{序号}；单文件流程的序号为 001。压缩不能保证达到指定大小，结果页会显示实际大小和是否超过限制。

人工步骤顶部显示进度，可继续或暂停。处理结果可保存为新流程，完整流程生成的结果会保留该流程的参数。OCR 文字可单独导出，原型不为扫描 PDF 创建真实的可搜索文字层。

已连接的交互

  • 导入本机 PDF/图片或拖入文件，实际读取 PDF 页数、大小、文字并生成页面预览。
  • PDF 阅读、分页、连续阅读、缩放、缩略图跳页、搜索与文档信息。
  • 页面选择、拖动排序、按钮前后移动、旋转、复制、删除、撤销/重做、合并、插入、提取、按范围拆分。
  • 压缩档位、图像质量、分辨率、灰度与文字保留参数；实际生成 PDF 并显示真实输出大小。
  • 手写签名绘制、撤销笔画、保存、图片签名、放置/拖动/缩放签名、表单文本、勾选、高亮、下划线、矩形与便签。
  • OCR 文字编辑、查找、复制与 TXT/Markdown 下载；按实际文字来源显示原生文字页和示例识别页数量，不提供虚构置信度。
  • 区域打码、二次确认、重建已标记页面后输出新 PDF。
  • 批量选择、操作配置、任务队列、逐项下载、失败与重试入口。
  • 页码、文字/图片水印的实时预览与 PDF 输出。
  • 完整处理流程的确认、执行、暂停、恢复、保存、编辑、删除和置顶；外观、默认参数、记录清除与重置。
  • 模拟 Pro 购买/恢复，以及快捷指令任务选择和试运行。
  • 新文件进入最近列表，结果可以重命名、下载、比较处理前后效果、继续处理或使用浏览器支持的系统分享。
  • 多个常用签名的选择、重命名与删除；个人填写资料的保存与调用。
  • 处理进度与取消，取消 OCR 不提交识别结果，取消批处理保留已完成项目和待处理项目。

本机保存与恢复

默认开启“在此浏览器保存文件与草稿”。PDF 源数据、导入文件、编辑后的页面、标注、阅读位置、当前草稿、流程进度、扫描页面和 OCR 修正文字保存到 IndexedDB。刷新后回到首页，由用户选择继续草稿，不自动执行未完成的任务。

签名库、个人填写资料、常用流程、偏好、免费任务计数和模拟购买状态保存到 localStorage。所有保存发生在当前浏览器，不上传文件，也不提供跨浏览器、跨设备或 iCloud 同步。

  • 在设置中关闭文件与草稿保存，会清除已持久保存的工作空间，当前会话仍可继续。
  • “清除已保存的文件与草稿”清除文件和工作空间；常用资料有独立清除入口。顶部重置可恢复整个原型的初始状态。
  • 草稿源文件缺失时，可重新选择原始 PDF。只有内容完全一致的原文件能重新关联，避免把标注恢复到错误文件上。
  • 浏览器禁用或无法写入本机存储时，界面会提示只能继续当前会话。
  • 浏览器清理站点数据、无痕模式以及本地 HTML 路径变化可能影响恢复。重要结果应实际下载；“已生成”不代表已保存到系统文件 App。

免费额度与购买演示

扫描、OCR、压缩目前各设为每月 3 次免费任务，成功完成才计数。次数用完时会在处理前提示，保留文件与编辑内容；完成模拟购买后，可以继续刚才中断的任务。

Pro 页面采用 ¥68 永久买断方案。这些额度与价格是用于评审的原型提案，尚未确定为正式商业规则。购买与恢复不调用 StoreKit，不发生真实支付；其余高级工具在原型中开放体验，不能据此判断正式版的完整权限策略。

原型边界

  • 相机扫描使用内置文档模拟拍摄；照片/文件选择实际调用浏览器文件选择器。
  • OCR 提取导入 PDF 中可读取的原生文字；扫描/图片 OCR 使用示例识别文本，不调用 Vision 或外部 OCR。
  • 密码、权限和移除密码只演示交互流程。下载的清理副本未加密，界面会明确标注。
  • 打码会把已标记页面重建为图像，并去掉底层 PDF 对象，但没有正式产品要求的安全验证与回归测试，不应用于真实敏感文件。文字匹配中的区域为演示定位，须人工核对。
  • 图片压缩会栅格化；“保留原生文字”模式保留导入 PDF 的原页面，可能无法降低大小。PDF 结果大小以实际输出为准。
  • 标注导出为固定内容，不实现可继续编辑的 AcroForm/annotation 字段。
  • 已旋转页面添加签名、页码或水印时，会栅格化以保持预览与输出的方向和位置一致，原生文字层不保留。
  • 水印的背景样式以降低透明度模拟，不重写原始 PDF 的内容层顺序。
  • 系统购买、家庭共享、原生快捷指令、Share Extension 和多窗口为流程预览，不触发系统能力或真实支付。
  • 浏览器支持 Web Share 时可实际分享文件；否则提供下载路径。源文件不会被覆盖。
  • 页面排序和编辑只影响原型的工作副本。本机持久保存、清除和恢复的范围见上文；保存到浏览器不能替代原生 App 的文件管理与数据保护实现。
  • 为避免原型占用过多内存，单次导入 PDF 限制为 100 页。

验证记录

  • 导入、页面整理、签名绘制/移动/缩放、水印、扫描演示、OCR 编辑和文字下载。
  • 重新读取实际导出的 PDF，检查页数、旋转信息和文件大小；验证范围拆分、压缩、页码、打码与批量重命名结果。
  • OCR/批处理取消、密码不一致、空文件列表、模板保存和导入引导。
  • 首次使用与回访首页、工具导入后返回、阅读页码保留、结果继续处理和处理前后比较。
  • 签名与页面草稿刷新恢复、扫描草稿恢复、OCR 修正恢复、缺失源文件重新关联和错误文件拒绝。
  • 完整流程的真实 PDF 输出、命名、参数保存与复用；签名库和填写资料持久保存。
  • 免费额度耗尽、模拟购买后继续任务、关闭草稿保存及清除工作空间。
  • 320px 和 390px 手机布局、iPad 预览、深色模式；各功能页面无横向溢出。
  • 全流程没有浏览器脚本错误，也没有 HTTP/HTTPS 请求。

尚未在真实 iPhone/iPad 或 Safari 中验收；HTML 原型的系统能力模拟不能替代原生 App 验收。

维护原型

源码位于 prototype-src/：template.html 包含界面与基础状态，controller.js 包含文档处理和操作，experience.js 包含首页、流程、结果、本机存储和个人资料交互；依赖位于 vendor/。构建脚本将这些内容与依赖嵌入单个 HTML，修改后重新生成：

node docs/prototype-src/build.mjs

内置依赖：PDF-lib 1.17.1（MIT）、PDF.js 3.11.174（Apache-2.0）、Lucide 0.468.0（ISC），各分发文件保留原许可头。HTML 文件不需要这些目录即可运行。
