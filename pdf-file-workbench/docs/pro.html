PaperFlow / 纸间 · StoreKit 产品说明

Pro 一次性买断

PaperFlow Pro 是一次性非消耗型内购，产品 ID 为 com.xiaolongxu.PaperFlow.pro.lifetime。它不自动续费，也不是周订阅、月订阅或年订阅。

Pro 权益

  • 无限 OCR、扫描、压缩和批处理。
  • 无水印导出。
  • 高级签名和敏感内容处理能力。
  • Shortcuts 自动化能力。

购买和恢复

购买页面会显示 Apple 为当前地区返回的价格。付款由 Apple App Store 处理；PaperFlow 不接收支付卡号。重新安装或更换设备后，可使用同一 Apple 账户在应用内恢复购买。家庭共享是否可用以 Apple 的当前规则和商品配置为准。

退款

退款、账单和付款方式由 Apple 处理，请通过 Apple 的购买记录或 Apple 支持渠道申请。
