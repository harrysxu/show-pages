# 纸间（PaperFlow）原生实现记录

## 支持范围

- 平台：iOS / iPadOS，最低部署目标 18.0。
- Bundle ID：`com.xiaolongxu.PaperFlow`。
- App Group：`group.com.xiaolongxu.PaperFlow`。
- 处理方式：文件、OCR、签名和结果全部在设备本地完成；不要求账号，不上传文件。
- 商业能力：StoreKit 2 永久买断 `com.xiaolongxu.PaperFlow.pro.lifetime`，免费扫描、OCR、压缩各每月 3 次，成功任务才计次。

## 已实现能力

- Files、照片、拖放、Share Extension、URL Scheme 导入 PDF 和常见图片；安全作用域书签、iCloud 下载等待、默认导出目录和自动改名防覆盖。
- PDF 阅读、连续/单页/双页、适应宽度/页面、目录、搜索高亮、阅读位置和真实信息页。
- 页面选择、范围选择、排序、倒序、旋转、复制、删除、提取、插入、合并、范围拆分和输出预览。
- 真实 PDF 压缩（DPI、质量、灰度、黑白、保留文字、目标大小估算）、页码、文字/图片水印和纸张尺寸适配。
- Vision 中文/英文 OCR、原生文字页识别、修正后可搜索 PDF、TXT/Markdown 导出。
- 手写和图片签名库、去背景、表单文字/复选框/单选/下拉字段、标注、原生批注选择转换、移动/缩放/样式、撤销重做、复制到多页。
- 永久打码：页面图像重建、元数据/附件/隐藏内容清理、QPDF 白名单验证、文本提取和搜索门禁。
- AES-256 密码保护/移除、打印/复制/编辑权限、元数据和附件清理。
- 批量压缩、合并、拆分、重命名、页码和水印；每项队列状态、逐项重试/跳过、多个输出、断点持久化。
- 常用流程、Shortcuts/App Intents、iPad 多窗口入口、文件拖出、深色模式、Dynamic Type、VoiceOver 标签和后台任务 lease。
- SwiftData 本地 JSON envelope、App Group 文件分层、草稿/撤销栈/扫描页面/OCR/批处理恢复、外部源文件书签恢复、保留期和孤立资源清理。

### iPhone 14 真机验收（2026-10-04）

主 App 与分享扩展签名已解决，已安装并实际运行于 iPhone 14 / iOS 27.0。首次完整回归为 34/35，其中 UI 16/16；唯一失败项为独立 `.xctestrun` 未激活 Scheme 的本地 StoreKit 配置。使用正确 Scheme 定向复测该项 1/1 通过，买断 / 恢复 / 退款撤销及额度权益同步均有通过证据，没有真实付款。35 个不同用例均已有通过记录，但首次完整结果包本身仍为 Failed；一次 0 用例的错误选择器重试不计入结果。

普通启动的 App 已验证真实 Files 保存 / 重新导入、本机默认目录书签跨进程重启恢复、重复保存自动生成 `_2` 副本且可读、真实分享扩展导入与主 App 消费、再次重启不重复消费。54 张 UI 测试截图及系统操作截图已保存。相机授权 / 启动与控件可用性通过，扫描成页自动化仍使用测试图片，尚未完成纸张实拍。详细范围和证据见 [真机验收记录](device-testing.md)。此次仅调整真机 / StoreKit 测试断言，未修改生产购买逻辑。

## 扫描交互修订（2026-10-01）

根据本轮反馈重新组织原生扫描界面：返回、拍摄、照片、页数及生成 PDF 固定可见；拍摄选项使用应用内部弹层；边缘、颜色、排序、重拍与输出参数集中到页面检查。新安装默认生成普通 PDF，已有 OCR 偏好保留；OCR 额度不足时可继续生成普通扫描 PDF。返回保留草稿，空草稿清理，重拍支持取消和单张照片替换，页面处理中禁止提前生成 PDF。

本次 3 项扫描数据测试、iPhone 与 iPad 各 4 项扫描 UI 测试通过，实际检查了首屏、页面检查、横屏和大字号截图。完整交互依据与验证边界见 [扫描交互修订](scan-ux.md)，截图在 `artifacts/native-ui/scan/`。HTML 原型扫描页尚未同步本轮原生调整。

## 全流程交互简化（2026-10-01）

原生实现按 [全流程交互简化评审](interaction-ux.md) 调整：首页与侧栏减少默认入口；工具主命令固定；高级选项折叠；签名保存后直接放置；OCR 默认连续生成 PDF；批处理配置和文件选择保持在当前任务；合并明确展示顺序；常用流程统一使用下一步，并支持暂停 / 恢复；结果页优先保存与分享，继续处理选择工具并携带生成文件。

行为修订包含编辑分享生成当前内容、打码分享必须确认、单工具参数隔离、默认压缩不限制大小、加密不默认清理附件 / 批注，以及导入取消和返回恢复任务上下文。实施清单、测试批次及边界见 [交互简化实施记录](interaction-implementation.md)。HTML 原型尚未同步这些原生调整。
