# 扫描交互修订

## 核心判断

扫描的主要任务是把纸张拍成 PDF。原界面同时呈现滤镜、自动拍摄、闪光灯、清晰度和 OCR，增加了第一次拍摄前的决策负担。主要操作放在滚动内容中，展开选项后完成按钮会移出屏幕。缺少稳定的返回入口，也没有区分普通扫描与文字识别的额度。

扫描功能保留，界面按实际操作阶段重新组织。

## 主流程

1. 从工作台、导航或其他入口进入扫描，顶部返回按钮回到进入前的页面。
2. 取景区域占据剩余空间。下方固定展示已拍页面入口、拍摄按钮、照片入口及生成 PDF。
3. 连续拍摄多页，可进入页面检查调整边缘、颜色、旋转、顺序、重拍或删除。
4. 点击生成 PDF，处理成功后进入结果页，可保存、分享或打开新文件。
5. 中途返回保留草稿，从首页继续；返回不删除已经拍摄的页面。

iPhone 横屏使用取景区域与操作区域并排的布局。iPad 保留导航，扫描内容居中。主要操作不依赖页面滚动。

## 控件归属

| 功能 | 用途 | 新位置 |
| --- | --- | --- |
| 自动边缘识别、透视校正 | 将拍摄的纸张校正为平整页面 | 默认处理，无需提前选择 |
| 自动增强、原色、灰度、黑白 | 调整纸面和文字的颜色、对比度 | 页面检查中的边缘与颜色编辑 |
| 自动拍摄 | 文档边缘稳定后触发拍摄，适用于连续多页 | 取景区域右上角的拍摄选项 |
| 闪光灯 | 给拍摄补光，设备没有闪光灯时不可用 | 拍摄选项 |
| 输出清晰度 | 选择输出图像的分辨率，影响文件大小和细节 | 页面检查中的输出选项，默认 300 DPI |
| OCR / 可搜索 PDF | 给扫描图像增加可搜索、可复制的文字层 | 页面检查中的输出选项，显示额外 OCR 额度 |

新安装默认关闭扫描后自动 OCR。已经保存的用户偏好继续生效。普通扫描只计扫描额度，开启 OCR 才额外计文字识别额度。

## 操作状态

- 没有页面：页面检查和生成 PDF 不可用，照片入口可用。
- 相机不可用：明确显示状态与可点击的照片入口，不显示可用的拍摄状态。
- 相机权限关闭：可打开系统设置，也可直接选择照片。
- 处理页面：暂停相机，避免重复触发；处理完成前禁止生成 PDF。
- 页面检查、选项弹层、照片选择、应用进入后台或 PDF 处理中：暂停相机，关闭后恢复。
- 重拍：明确标注页码，可取消；成功拍摄或选择照片替换所选页。重拍选择照片仅允许一张。
- 自动拍摄：同一稳定文档不会因为处理完成、相机恢复而自动重复拍摄。
- 生成失败、取消或额度不足：保留页面草稿，可调整选项重试。
- OCR 额度用完：可直接选择仅生成扫描 PDF，不强制购买或放弃扫描。
- 删除所有页面：清除空扫描草稿，不展示没有内容的继续入口。

## 验收边界

本次新增验证覆盖主操作可见、返回点击范围、选项打开关闭、空页面状态、重拍取消、照片替换、草稿保留、普通扫描额度、真实多页 PDF 生成及横屏布局。模拟器使用已有 PDF 页面生成测试图像，经过真实扫描处理引擎；没有伪造生产相机。

相机取景、真实自动拍摄、闪光灯、旋转方向及最低版本设备表现仍需真机验收。旧版 HTML 扫描界面仍保留原样，本文件记录本次原生扫描界面的修订依据。
